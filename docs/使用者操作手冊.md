# 小怪獸桌球 — 系統使用者操作手冊

> 版本：v1.0（正式上線版）
> 適用對象：店長、教練、顧客（含未登入訪客）

---

## 1. 系統簡介

「小怪獸桌球」網站提供三大功能：

| 功能 | 說明 |
|---|---|
| 官方網站 | 課程介紹、最新優惠活動、教練陣容、獲獎榮耀、聯絡資訊 |
| 教練預約 | 線上查看教練可授課時段並直接預約；未加入會員也可申請 30 分鐘試教體驗 |
| 球具商城 | 瀏覽球具商品、加入購物車、線上下單（付款與取貨由專人聯繫確認） |

### 網站導覽列

頁面最上方的導覽列（手機版請點右上角 ☰ 選單）：

- **首頁**：球館介紹、課程介紹、最新優惠活動、教練陣容、獲獎榮耀
- **預約教練**：教練列表 → 點入教練頁面選時段預約
- **球具商城**：商品列表與購物車
- **聯絡我們**：地址、電話、官方 LINE、Facebook 粉絲專頁
- **右上角**：未登入時顯示「登入／註冊」；登入後顯示您的姓名，點擊可進入「**個人後台**」或「登出」
- **購物車圖示**：隨時可點擊查看購物車內容

## 2. 註冊與登入

本系統**不使用密碼**，以「姓名＋手機號碼」作為登入憑證，請務必牢記註冊時填寫的資料。

### 顧客註冊（自助）

1. 點擊右上角「**註冊**」
2. 填寫「姓名」與「電話」→ 按「註冊」
3. 註冊成功後系統會自動登入

> 注意：每支手機號碼只能註冊一個帳號。

### 登入

1. 點擊右上角「**登入**」
2. 輸入註冊時的「姓名」與「電話」（兩者都必須正確）→ 按「登入」
3. 若顯示「姓名或電話錯誤」，請確認輸入內容；仍無法登入請聯繫店長協助查詢或修改資料

> 登入有效期為 **24 小時**，逾期需重新登入。

### 角色說明

| 角色 | 帳號來源 |
|---|---|
| 顧客 | 自行於網站註冊 |
| 教練 | 由店長於後台建立，或由店長將既有帳號指派為教練 |
| 店長 | 系統初始帳號，或由其他店長指派 |

## 3. 未登入訪客可以做什麼

**不需登入即可：**

- 瀏覽首頁全部內容（課程介紹、優惠活動、教練陣容、獲獎榮耀）
- 瀏覽「聯絡我們」聯絡資訊
- 瀏覽教練列表與每位教練的可預約時段
- 瀏覽商城全部上架商品與商品詳情，並可先將商品加入購物車
- **申請 30 分鐘試教體驗**（見下方說明）

**需要登入才能：**

- 預約教練正式課程（點時段時會引導您先登入）
- 購物車結帳下單（點「確認結帳」會引導您先登入）
- 查看個人後台（我的資料／我的預約／我的訂單）

### 訪客申請試教（30 分鐘體驗課）

適合還沒加入會員、想先體驗課程的朋友。**試教需要「試教密碼」，請先向小怪獸老闆索取。**

1. 進入「預約教練」→ 點選想體驗的教練
2. 捲動到下方橘色的「**申請試教**」區塊，點選一個 30 分鐘時段
3. 填寫「姓名」、「手機號碼」、「試教密碼」→ 按「送出申請」
4. 申請送出後為「**待審核**」狀態，**需等店長審核核准後才正式成立**，店家將以您留的手機號碼與您聯繫確認

## 4. 顧客操作指南

### 4.1 預約教練課程

1. 導覽列點「**預約教練**」，瀏覽教練列表（可看到專長、年資、得獎頭銜）
2. 點選教練進入個人頁面，下方為「選擇上課時段」：
   - 🟩 **綠色格子**：可預約（1 小時）
   - 🟦 **藍色格子**：剩餘 30 分鐘的短時段，也可預約
   - ⬜ **灰色格子**：已被預約
3. 點擊綠色或藍色格子 → 確認時段 → **預約即刻成立**（狀態「已確認」），不需等教練回覆
4. 可至「個人後台 → 我的預約」查看所有預約

> 只會顯示未來的時段；過期時段自動隱藏。

### 4.2 取消預約

取消預約需經店長審核，並非立即取消：

1. 「個人後台 → 我的預約」找到該筆預約，點「**申請取消**」
2. 狀態變為「**申請取消中**」，並建議主動聯繫小怪獸老闆協助處理
3. 店長同意後狀態變為「已取消」；若店長拒絕，預約恢復原狀

### 4.3 球具商城購物

1. 導覽列點「**球具商城**」瀏覽商品，點入商品可看圖片、價格、庫存與描述
2. 選擇數量 → 「**加入購物車**」
3. 點右上角購物車圖示進入購物車，可調整數量或移除商品
4. 按「**確認結帳**」→ 訂單成立（狀態「待處理」）
5. **本系統不做線上付款**：下單後將有專人依您的手機號碼主動聯繫，確認訂單細節、付款與取貨方式
6. 可至「個人後台 → 我的訂單」隨時查詢訂單狀態

> 下單前請確認「個人後台 → 我的資料」中的手機號碼正確，以便店家聯繫。

### 4.4 我的資料

「個人後台 → 我的資料」可查看姓名、手機、Email、Line ID、生日、性別。

- 尚未填寫的欄位（Email／Line ID／生日／性別）可自行填寫一次並儲存
- **已填寫的資料無法自行修改**（含姓名與手機）；如需更改，請聯繫店長協助

## 5. 教練操作指南

教練登入後，右上角選單進入「**個人後台**」。

### 5.1 編輯個人資料（官網形象頁）

後台左上角「**編輯個人資料**」按鈕，這裡的內容會顯示在官網首頁「教練陣容」與您的預約頁面：

- **上傳大頭照**
- 填寫**專長**、**年資**、**個人簡介**
- **獎項／頭銜**：可新增（例：大專盃個人單打冠軍）、雙擊或點 ✏️ 編輯、刪除、以 ▲▼ 調整顯示順序

### 5.2 我的時段（開放可授課時間）

「**我的時段**」分頁：

1. 選擇「日期」、「開始時間」、「結束時間」（以 30 分鐘為間隔）→ 按「**新增時段**」
2. 開放後，顧客即可在您的預約頁面以 1 小時為單位預約
3. 時段狀態：`available` 可預約／`booked` 已被預約
4. 尚未被預約的時段可直接「刪除」；**已被預約的時段無法刪除**（如需異動請聯繫店長）

> 只能新增今天以後的日期；結束時間必須晚於開始時間。

### 5.3 預約申請（查看收到的預約）

「**預約申請**」分頁分成兩區：

- **一般預約**：顯示顧客姓名、手機、時段、備註、狀態。顧客預約成立後即為「已確認」，您無需操作
- **試教申請**：顯示試教申請人姓名、手機、30 分鐘時段與審核狀態（試教由**店長**負責審核）

**教練申請取消課程**：對狀態「已確認」的預約（或「已核准」的試教）可點「**申請取消**」，送出後需等店長審核才正式取消。

### 5.4 我的薪資（試算）

「**我的薪資**」分頁：

1. 選擇「計算區間」與「時薪」→ 按「**計算薪資**」
2. 系統依區間內的課堂（不含已取消）計算：課堂數、總時數、應收薪資，並列出每堂明細

> 此為試算功能，實際薪資以與店長約定為準。

## 6. 店長操作指南

店長登入後進入「**個人後台**」，共有 8 個管理分頁。

### 6.1 商品管理

- 「**新增商品**」：填寫名稱、描述、價格、庫存
- **新增後商品預設為「已下架」**，需點「上架」才會在商城顯示
- 「**圖片**」：上傳商品圖片（重新上傳會取代原圖片）
- 「**編輯**」：修改名稱、描述、價格、庫存
- 「**上架／下架**」：一鍵切換；「**刪除**」：永久刪除（無法復原）

### 6.2 訂單管理

- 查看所有顧客訂單：顧客、金額、狀態、下單時間
- 以下拉選單更新狀態：**待處理 → 已付款 → 已完成**（或已取消）
- 顧客下單時系統已自動扣庫存；顧客端「我的訂單」會同步看到您更新的狀態
- 可刪除訂單記錄（無法復原）

> 建議流程：收到新訂單（待處理）→ 電話聯繫顧客確認付款與取貨 → 收款後改「已付款」→ 交貨後改「已完成」。

### 6.3 帳號管理

- 查看所有會員：姓名、電話、Email、Line ID、生日、性別、角色
- 「**新增帳號**」：填姓名、電話並指定角色（教練／店長／顧客）——**教練與店長帳號皆由此建立**
- **變更角色**：直接在列表的角色下拉選單切換（例如把顧客升級為教練）
- 「**編輯**」：可修改會員的**全部**基本資料（姓名、手機、Email、Line ID、生日、性別）——會員自己僅能填寫空白欄位，修改需由店長代為處理

### 6.4 班表管理

替教練代管可授課時段：

1. 「選擇教練」下拉選單選定教練
2. 選擇日期、開始／結束時間 → 「**新增時段**」
3. 下方列表顯示該教練所有時段與狀態（可預約／已預約／已取消），可刪除時段

> 店長刪除「已預約」的時段時，原預約記錄仍會保留，請記得於「預約總覽」一併處理並通知學員。

### 6.5 預約總覽

全店預約的總管理中心：

- 查看所有預約：學員、教練、時段、狀態、申請時間
- 「**修改**」：替任何預約**改期**（重新指定日期與起訖時間），適用於學員或教練來電要求調課
- 「**審核取消**」：學員或教練送出取消申請後（狀態「申請取消中」），由您點「**同意取消**」或「**拒絕申請**」（拒絕後預約恢復原狀）
- 可刪除預約記錄（無法復原）
- 下方另列出「**已核准的試教預約**」，方便對照當日課表

### 6.6 試教管理

- **試教密碼設定**：頁面上方可查看目前密碼並更新。**未設定密碼時，試教功能對外關閉**。此密碼由您口頭提供給想體驗的客人
- **審核試教申請**：對「待審核」的申請點「**核准**」或「**拒絕**」；核准後該 30 分鐘時段即被佔用
- **審核試教取消**：教練申請取消已核准的試教後，由您「同意取消」或「拒絕申請」
- 可刪除試教記錄

### 6.7 獲獎榮譽

管理官網首頁「獲獎榮耀」區塊：

- 輸入「年份」與「獎項名稱」→ 「**新增獎項**」，即時顯示於官網首頁
- 可刪除獎項

### 6.8 教練薪資

計算教練應付薪資：

1. 選擇「教練」、「計算區間」、「時薪」→ 「**計算薪資**」
2. 顯示課堂數、總時數、**應付薪資**，以及每堂課的日期、時段、學員、時數、小計（不含已取消的課）

### 其他店長權限

- 店長也可以像顧客一樣在教練頁面預約時段（例如替來電客人先卡位，預約會記在店長帳號下，可再於「預約總覽」改期管理）
- 店長在教練頁面也看得到「申請試教」區塊，可代客人送出試教申請

### 預約狀態

| 申請取消中 | 教練申請取消，等待店長審核 |
| 已取消 | 已取消 |

| 狀態 | 意義 |
|---|---|
| 待處理 | 訂單成立，等待店家聯繫確認 |
| 已付款 | 店家已確認收款 |
| 已完成 | 商品已交付 |
| 已取消 | 訂單取消 |

## 9. 常見問題（FAQ）

**Q：忘記註冊時填的姓名或電話，登入不了怎麼辦？**
A：請聯繫店長，店長可在「帳號管理」查詢並修正您的資料。

**Q：我想改姓名／手機／Email，但系統不給改？**
A：會員只能「填寫」尚未填過的欄位，修改既有資料請聯繫店長代為處理。

**Q：預約後多久成立？**
A：一般預約點選時段後**立即成立**，不需等教練確認。試教申請則需等店長審核。

**Q：預約可以直接取消嗎？**
A：不行，取消採申請制。送出「申請取消」後需經店長審核才會正式取消，建議同時主動聯繫小怪獸老闆。

**Q：下單後怎麼付款？**
A：系統不提供線上付款。訂單成立後，店家會依您留的手機號碼主動聯繫，確認付款與取貨方式。

**Q：試教密碼哪裡拿？**
